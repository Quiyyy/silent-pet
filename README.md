# silent pet

一个安静的 Codex v2 桌面宠物项目。当前角色名称为 **猎豹**：白发、骨角、绿披风，赤脚、手持卷轴。

包含九组状态动画、16 个顺时针视线方向及独立默认姿势，重点改善动作循环、裁帧造成的尺寸跳动和方向切换。

## 安装

将仓库根目录的 `pet.json` 与 `spritesheet.webp` 放在同一个宠物目录中：

```text
~/.codex/pets/bone-horn-sorceress/
  pet.json
  spritesheet.webp
```

若配置了 `CODEX_HOME`，则使用该目录下的 `pets/bone-horn-sorceress/`。更新已有宠物前，请备份原目录。

项目名为 **silent pet**，宠物 ID 仍为 `bone-horn-sorceress`，显示名称仍为“猎豹”，便于替换现有宠物。

## 动画布局

图集为 **1536 × 2288**，8 列 × 11 行，每格 **192 × 208**。`spriteVersionNumber` 为 `2`。

| 行 | 状态 | 动画帧数 |
|---|---|---:|
| 0 | idle：警觉休息与微呼吸 | 6 |
| 1 | running-right：向右轻步 | 8 |
| 2 | running-left：向左轻步 | 8 |
| 3 | waving：招手 | 4 |
| 4 | jumping：亲近回应（兼容原生悬停槽位） | 5 |
| 5 | failed：失落反应 | 8 |
| 6 | waiting：期待用户回应 | 6 |
| 7 | running：读卷轴、处理任务 | 6 |
| 8 | review：检查结果 | 6 |
| 9–10 | 视线方向 | 16 |

第 0 行第 6 列（从 0 开始计数）保存 v2 默认视线姿势。其他未使用格保持透明。

视线以屏幕正上方为 `000`，按每步 22.5° 顺时针排列；`090` 为右，`180` 为下，`270` 为左。默认姿势独立于 `000`。

### 招手什么时候出现

当前Codex客户端将“首次唤醒问候”映射到招手，问候窗口约8秒，并按宠物ID去重，因此同一宠物通常不会反复招手。普通鼠标悬停是亲近回应；拖动或其它较高优先级状态可能覆盖问候。预览页的“招手”按钮可随时查看。这一结论来自客户端静态代码核对，未进行原生实时触发验收。

## 舒缓亲近修复（已保留）

亲近五帧改为持续半眯眼和微笑，只有极轻微呼吸；原生客户端840ms循环不变，避免每轮快速闭眼、睁眼和点头。浏览器互动体验的一次回应延长至2.4秒，悬停触发500ms，冷却4秒。

## 亲近与注视互动

亲近动作保持柔和半眯眼和微笑，用五帧极轻微呼吸变化维持自然感，保持脚底、卷轴和整体比例稳定。它占用现有的 `jumping` 槽位，保留 v2 格式。

| 行为 | 安装到 Codex | 本地预览的“互动体验” |
|---|---|---|
| 鼠标悬停身体 | 播放亲近槽位，是否循环由客户端控制 | 停留 500 ms 后回应一次，持续 2.4 秒 |
| 空闲时鼠标靠近 | 未在本项目中增加原生触发能力 | 180 px 内关注，210 px 外恢复待机 |
| 点击亲近 | 点击行为仍由客户端控制 | 播放 2.4 秒，从开始计 4 秒冷却，不排队重复 |
| 拖动 | 使用原有拖动动作 | 超过 8 px 进入拖动，松手不触发亲近 |
| 任务状态与减少动态效果 | 由客户端控制 | 任务优先；可切换静态帧，支持键盘操作 |

预览中的距离均为 CSS 像素；视线有中心死区与角度滞回，避免方向分界抖动。完整说明、测试范围和已知限制见[互动设计与验收](docs/interaction-2026-09-19.md)。

## 本地动作检查

在仓库根目录启动本地服务：

```bash
python -m http.server 8768 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8768/preview/](http://127.0.0.1:8768/preview/)，点击“进入互动体验”。

预览器支持九种状态、16方向、默认姿势、暂停与逐帧、0.5/1/2倍速、深浅背景和放大检查，也可运行工作、拖动、亲近三种连续切换场景。指针跟随仅在预览区内生效，不代表桌面客户端的触发方式。状态间直接切换原始帧，不使用淡入淡出掩盖问题。

## 自检

```bash
npm test
python -m pip install -r requirements.txt
python tools/validate_pet.py
```

Node测试覆盖帧时长边界、16方向映射、指针象限、状态序列，以及互动冷却、悬停防重入、方向防抖、拖动优先、取消和减少动态效果；Python检查图集版本、尺寸、有效/空白格、透明像素和发布哈希。结构检查不能代替正常尺寸的动作、视线和跨状态视觉验收。
