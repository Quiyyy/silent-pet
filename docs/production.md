# 制作说明

本项目保存最终可安装成果、选定源图及本次生成规范。图像由内置 image_gen 根据原角色参考制作，源条带为单行完整动作或完整方向族。生成具有随机性，相同提示不能保证再次得到完全相同的像素。

## 最终约束

- 保留白发、骨角头骨帽、绿披风、绿眼睛、盔甲和卷轴。
- idle采用安静呼吸和眨眼；waiting期待回应，running为读卷轴处理任务，review为温和检查。
- 左跑因旧逐槽镜像产生边缘裁切，改为独立生成，并保留完整交替步态。
- jumping改为五帧浅蹲、小幅起跳、峰值、下降与回落；生成目标总运动高度不超过站立高度约1.03倍，实际轻微跨状态尺寸差保留在QA记录中。
- 四主方向先行批准，再生成完整的row9与row10；row10曾出现后3格向右上的错误，失败候选未进入本项目。
- 最终row10由270左向000上平稳过渡，后3格保持左上，不能镜像或翻转下身与卷轴。

## 图像处理

逐行采用共享viewport与共享缩放，保留真实姿态位移；没有将每格独立放大以掩盖差异。方向行按完整群组提取并与默认姿势对齐，第二行复用第一行的缩放。完整8×11图集仅执行一次边缘去色，alpha保持不变。

图集与源图均是正常图像文件。后续编辑应维持每行动画语义、格数、帧顺序和透明区，并重新检查动作与视线，不应直接将单个独立生成的方向格拼入已有方向族。

## 文件映射

`production.json`列出可追溯的提示词、源条带及参考。`docs/qa/`保存去除本机绝对路径后的验收证据；第三方技能的运行脚本和本机安装备份不属于本仓库。
