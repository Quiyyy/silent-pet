# 制作说明

当前版本为 2026-09-20 赤脚与招手修复版。角色外观以 [角色约束](character-spec.md) 为准；最终改动、触发规则和验收边界见 [当前制作与验收](barefoot-wave-2026-09-20.md)。

内置 image_gen 生成选定角色母图，随后按用户授权进行局部原画修复、连续皮肤变形、双骨骼逆运动学与确定性图集合成。脚部在所有状态中统一为赤脚。最终8×11图集只做一次边缘去色，alpha保持不变。

## 当前来源

- `source/preclean/spritesheet.png`：当前已批准的全部姿态，尚未做最终边缘清理。后续修改从此开始。
- `source/current-rows/`：同一图集的11行，格子已经注册为192×208。
- `source/masters/`：本轮实际生成原图。中间不合格招手母图标记在production.json，不能用于安装。
- `source/rig/master.png`、`source/wave/master.png`：选定裁切母图；`source/rig/layers/`为确定性派生图层。
- `tools/render_gait.py`：连续赤脚步态与可选招手渲染；`tools/test_gait.py`：轨迹、接触与像素保护检查。
- `production.json`：当前来源及历史生成映射；`prompts/masters/`保存实际生成提示词。
- `docs/qa/`：去除本机路径的验收证据；`docs/artifact.json`指定当前验收文件。

`source/reference.png`、`source/rows/`、旧提示词、旧版说明及旧QA保留历史追溯。早期素材中的鞋与额外手臂已经被拒绝，不能作为后续制作依据。

## 方向与动作

保留九个宿主状态及其帧数。亲近动作占用jumping槽位，保持半眯眼微笑和轻微呼吸；实际触发由客户端控制。左右移动逐帧镜像，新招手移动原有右臂，始终只有两臂两手。

16方向以屏幕正上方为000，每22.5度顺时针一格；默认姿势独立。方向头脸区域与此前通过盲测的版本像素相同，本轮只统一脚部并重新检查动作切换和方向循环。不能宣称整格未变或本轮重做了方向盲测。

结构测试、运动测试、视觉检查、浏览器交互和原生桌面测试是不同范围，必须分别记录。本轮未进行原生桌面实时播放验收。
