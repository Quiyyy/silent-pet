# 直立分层步态修复（2026-09-20）

上一版左右移动存在前倾与腿部相位不连贯的问题。本轮在用户明确允许程序化分层骨骼动画后，改为从一张直立侧身原画拆出身体、腿和靴子，再按同一连续轨迹渲染八帧。

## 实现结果

- 头、肩、躯干及卷轴保持直立，不旋转或缩放；仅有不超过0.35像素的垂直起伏。
- 近腿与远腿使用独立关节、固定遮挡顺序，相差半个周期。
- 脚先接地承重，再向后推移，经低弧线摆回前方；步幅参数为正负12像素，抬脚最多4像素。
- 使用双骨骼求解保持髋、膝、踝连续连接；髋部包边覆盖关节，避免切片接缝。
- 左向由右向逐帧镜像，保留帧序和相位。
- 除左右移动两行外，整个图集其它RGBA像素完全不变，保留舒缓亲近和16方向。

静态原画来自此前生成的侧身姿态；只复用角色外观，原生成行的步态并未被当成合格动画使用。原画、拆分图层和渲染代码都已保存。

## 复现渲染与检查

需要 Pillow，安装依赖后运行：

```bash
python tools/render_gait.py --source source/rig/master.png --output output/rig
python tools/test_gait.py --root output/rig --renderer tools/render_gait.py
```

产物是未做最终图集边缘清理的左右八帧、图层、轨迹数据及QA预览。发布图集再经v2合成和单次边缘清理。调整参数后应重新完成视觉和结构验收，不能只根据关节数学检查直接发布。

## 验收

- 17项Node逻辑回归测试通过。
- 1,001个连续采样点：始终至少一只脚支撑，关节解合法、骨长稳定、周期闭合。
- 八帧解剖部件保持连通，左向与右向的渲染帧精确镜像。
- 独立视觉审核通过：上身无前倾，换脚顺序、髋膝踝接缝、首尾及待机切换没有阻断问题。
- v2图集1536×2288验证通过；单次边缘清理保持alpha不变。
- 独立无界面Chrome 153实际输入回归通过：九状态、十六方向、左右八帧播放、悬停单次触发、快速点击防重启、拖动换向与释放、任务优先、减少动态效果、键盘触发与取消、深色和2倍显示。
- 浏览器观测悬停约496ms后触发，亲近回应约2403ms，持续停留5秒只触发一次；控制台无错误。

可复用的浏览器测试脚本为 `tools/test_preview.cjs`，需要Playwright和对应浏览器；可通过 `PREVIEW_URL` 与 `PLAYWRIGHT_CHANNEL` 指定本地地址和浏览器。

浏览器测试运行在独立测试实例，不操作用户现有浏览器或Codex桌面窗口。原生桌面客户端的实际重新加载状态没有自动核验。

## 已知表现限制

这是轻缓的小步移动，交叉帧双靴会重叠。原生客户端固定末帧220ms，其余帧120ms，仍可能感到轻微停拍；本轮没有修改客户端程序或帧时长。更完整的转身过渡和高帧率移动需要宿主支持。

## 安装

安装仍使用 `bone-horn-sorceress` ID 和现有名称。替换文件前保存备份，安装后核对SHA-256与验收版本一致。客户端若还显示旧动作，请切换其它宠物再选回猎豹，必要时完整重启Codex。
