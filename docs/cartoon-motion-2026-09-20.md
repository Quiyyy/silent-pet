# 短直卡通腿与招手局部运动

图集 SHA-256：`e9135f701500d2679322f8490999d5e4063b830db9ae63a8d771756d0b3ed9fe`。保持 Codex v2、1536×2288、9组动作、16视线方向和独立默认姿势。

## 问题与修复

上一版移动使用偏长、带肌肉轮廓的腿，再施加膝踝网格变形，出现 S 形、尖褶和脚背拉长。现重新制作短直卡通母图，让整条绘制好的腿小幅摆动和交替抬起。腿宽、脚掌和骨骼比例不随每帧变化，身体保持直立。

站姿、招手与视线也统一短直腿。上半身整体下移8px，保留头脸与卷轴形状；下肢区由38px收短至30px，足底保持在原基线。58个非移动格进行同样比例处理，其中54格的上半身像素严格保持后平移，招手另修手部。

招手原来的位置权重没有上边界，误把左角、头骨和头发一起拉动。现在只变换分离的手掌图层，静态身体与背景保持固定。最终四帧变化范围约 x29–67/y71–110，头角、上发和脸部逐像素一致。

制作中拦截了一版视线腿外侧 V 形缺口：暖色披风碎片混入了腿部宽度统计。修复为先隔离真实腿的连通区域，再做轮廓处理；该候选没有安装。完整记录见 `qa/cartoon-repair-decisions.json`。

## 可复现材料

`source/preclean/spritesheet.png` 是本版已批准的未清理基线。不要用历史含鞋、肌肉腿或膝踝变形图集覆盖它。

```bash
python tools/render_gait.py --output output/motion --walk-source source/rig/master.png --wave-source source/wave/master.png
```

此命令重建左右移动和招手20帧。其余状态保留当前未清理基线。`tools/shape_cartoon_legs.py` 提供本轮一次性短腿修复和招手母图的形状处理；不要对已修好的整图重复应用，以免再次下移上半身。

运动测试还读取完成清理后的图集：将最终图集置于 `output/motion/final/spritesheet-extended.webp` 后运行 `python tools/test_gait.py --root output/motion`。视觉复核仍是必要环节，参数或像素回归不能替代实际观感。
