# 角色约束

这是当前制作约束。用户在 2026-09-20 明确指出角色赤脚、招手不能有多余手臂；早期生成提示中的鞋、靴、手套描述不能作为设计依据。

- 保留白发、骨角头骨帽、绿眼、棕肤色、绿色披风、浅色包裹服饰和卷轴。
- 所有动作和视线均赤脚，能辨认脚跟、足弓与脚趾；不得出现鞋底、鞋头或靴口。包裹服饰不能覆盖脚掌。
- 始终只有两臂两手、两腿两脚。招手时角色右臂（画面左侧）从卷轴移开，另一只手独立托住卷轴；卷轴左缘不得再保留第三只手或前臂。
- 腿型采用短直卡通比例，轮廓简洁，脚掌小巧；不得画成人式肌肉小腿、细长脚踝，不得用强膝踝扭曲制造步态。
- 招手仅移动隔离的手掌/必要手腕区域；角、头骨、上方头发和脸部保持固定。
- 手掌、前臂应与头、肩及另一只手协调。肩肘腕连续，腿部转折没有断层。
- 左右移动保持直立，交替支撑，脚掌贴地；身体和披风轻微跟随。不能只横移整个人或用跳帧代替换步。

后续修订以 `source/preclean/spritesheet.png` 和当前 `source/rig/master.png`、`source/wave/master.png` 为起点。`source/reference.png`、`source/rows/` 和旧提示词保留为历史来源，不可用含鞋旧条带覆盖当前图集。

验收必须包含：全部有效格足部、招手四帧两臂两手与比例、左右完整循环、待机/拖动/招手/亲近切换，以及默认姿势与16方向。结构和运动测试不能代替视觉验收。
