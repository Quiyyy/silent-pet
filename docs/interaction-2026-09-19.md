# 亲近、注视与互动验收（2026-09-19）

## 设计结果

为猎豹增加轻歪头、眯眼微笑、恢复姿势的五帧亲近动作。使用已有 `jumping` 行（第 4 行），没有增加自定义 manifest 字段，也没有修改 Codex 客户端。

正常身体、脚、卷轴保持稳定，表情承担主要反馈。其它八组动作、独立默认帧和全部 16 个视线帧与上一版 RGBA 完全一致，保留原有方向盲测与连续性验收证据；对应哈希和范围见 [preservation.json](qa/preservation.json)。

## 能力边界

- 安装包只替换图像。Codex 原生悬停可使用新的亲近行，循环、点击打开窗口、拖动、任务状态以及视线输入仍由宿主客户端决定。
- 普通鼠标靠近自动注视、点击播放一次、冷却、任务优先及减少动态效果，属于本仓库浏览器预览里的互动原型。不能通过复制 `pet.json` 和图片将这些代码加入 Codex。
- 当前客户端行为来自 Windows AppX 包版本 `26.915.4065.0` 的本地静态代码检查，不是 About 页面读数或本轮桌面运行验收。

## 预览操作

点击“进入互动体验”，在预览区内移动鼠标：

1. 距离宠物中心 180 CSS px 内进入关注，超过 210 px 恢复待机。中心 8 px 为默认姿势；方向分界额外保留 3° 滞回。
2. 在非透明身体区域悬停 350 ms，或轻点身体，回应一次。2.4 秒冷却从动作开始计算；冷却内的事件被消费，不排队，不重启动画。
3. 按住移动超过 8 px 后拖动优先，切换左右移动动作，限制在预览区内；拖动后松手不触发亲近。
4. 选择“工作中”“等待回应”等任务状态时，任务展示优先于注视与亲近；拖动仍可使用。
5. 可用 Tab 聚焦宠物，再按 Enter/Space 亲近，Esc 取消。减少动态效果默认跟随系统设置，也可手动选择。

长时间停留只触发一次，离开后再次进入才重新计时。交互使用真实时间，不受逐帧检查的播放倍速影响。点击动作/方向按钮即可返回检查模式。

## 验收结果与限制

- Node 自动测试：15 项通过，覆盖帧序列、16 方向、靠近/离开滞回、中心死区、方向防抖、快速点击、悬停单次触发、冷却消费、拖动中断、指针取消/多指针、任务优先和减少动态效果。
- 语法检查：`node --check preview/app.mjs` 通过。
- 图集：v2、1536 × 2288、有效与空白格、透明像素及单次边缘清理验证通过，清理保持 alpha 不变。
- 源图已通过自动组件提取检查。最终采用共享视口的 stable-slots，保留全行尺度与基线；其必须人工确认的切片警告交由本轮独立视觉审核。
- 原尺寸浅/深背景的亲近五帧及 idle 衔接：见 [视觉检查](qa/affection-visual-qa.json) 和 [衔接图](../previews/affection-transition.png)。
- 本地 HTTP 页面和脚本资源返回 200，JS 模块 MIME 正确。
- **浏览器实际输入验收未完成**：自动化工具两次初始化均失败，错误为 `windows sandbox failed: helper_unknown_error: setup refresh had errors`。HTTP 和单元测试不等于浏览器交互验收。
- **Codex 桌面原生实测未完成**：未自动控制宿主应用；本轮安装只核对文件内容、格式和哈希。旧版浏览器验收记录不作为新互动功能的证明。
