# 猎手性格优化与验收（2026-09-19）

## 设计范围

沿用现有猎豹的骨质头饰、白发、深肤色、绿眼、绿披风和手持卷轴，在四组动作中加强安静、警觉、轻巧、从容的性格：

- idle：轻微呼吸与眼睑变化，保持安静观察，减少明显闭眼与点头的重复感。
- running-right / running-left：短步幅、支撑腿交替的轻步移动，身体与卷轴稳定。
- review：从卷轴抬眼、轻微眉眼变化和克制微笑，表达对结果的自信。

本轮对卷轴仅作轻微姿态调整；没有改成完全收卷，也没有新增武器道具。整体角色设计与已批准的视线、亲近动作保持兼容。

灵感来自“二次元猎宝”卡面制作记录中的“战术大师”“本能反应”“独门技术”的动作描述，实际生成以本项目已批准的角色图为视觉依据：

- [Mod 发布页](https://steamcommunity.com/sharedfiles/filedetails/?id=3507627229)
- [卡面制作记录](https://www.vgover.com/news/166797)

## 制作与保留

使用内置 image_gen 分别生成三张完整横向动作条带。idle 采用第二次针对眼神与留白修正的结果；右向拖动比较两次结果后选用第一版。经过视觉确认，右向动作无可读文字或必须固定侧的标志，使用确定性逐帧水平镜像生成左向，保留帧序。

原始输出是真正 RGBA。先检查组件与外边界，再采用全行共享视口裁帧，随后合成 8×11 图集并执行一次边缘清理。默认视线格与原 16 个方向沿用原有注册参数。

所有未改有效格与上一版 RGBA 完全一致，因此对应的方向盲测、方向语义与连续性证据继续有效；新待机与这些保留动作的边界需要本轮重新检查。

源图、实际选用提示词、镜像来源及修正尝试记录保存在 source、prompts 和 production.json 中。

## 验收

结构、alpha 保留、未改像素一致性、原尺寸新旧对照与跨状态衔接分别记录，避免把格式正确当成动作自然。完整文件索引见 [artifact.json](artifact.json)。

- 新动作的组件检查通过，外侧主体没有被源画布截断。
- stable-slots 提取警告要求目视确认，不用放宽阈值直接忽略。
- 最终 v2 图集为 1536×2288，每格 192×208；结构验证无错误或警告。
- 单次边缘清理保持 alpha 不变。
- 四组新动作之外，包括默认格和全部视线，逐像素相同。
- 独立视觉检查关注身份、体积、脚底、手与卷轴、首尾闭环、idle 与亲近/工作/完成/拖动/视线的切换。
- 浏览器交互自动化工具本轮仍无法初始化（Windows sandbox helper 错误）。有序帧、GIF 时长、结构和单元测试不等于浏览器或 Codex 桌面实测。

## 本地生效方式

安装时保留 pet ID 和显示名称，原子替换图集，并核对安装文件与发布文件 SHA-256 相同。桌面客户端对自定义宠物数据有长期缓存：若仍显示旧动作，先切换其他宠物再选回猎豹；仍未更新时，完整退出并重新打开 Codex。

本项目没有修改客户端程序。普通鼠标靠近、点击亲近及冷却属于浏览器原型；原生客户端仍使用其原有触发规则。实际运行后的加载状态未自动核验。
