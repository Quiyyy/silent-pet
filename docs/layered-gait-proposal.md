# 左右移动分层制作方案（已实施）

状态：用户于2026-09-20明确授权，已完成程序化分层、骨骼渲染及验收。最终参数和结果见 [制作记录](layered-gait-2026-09-20.md)。

## 输入与范围
- 沿用现有角色的脸、头饰、白发、躯干、卷轴和画风。
- 选取上半身直立的生成参考作为素材基础，准备躯干、近腿大腿/小腿/靴子、远腿大腿/小腿/靴子。
- 只替换 running-right / running-left；其它动作和16方向保持不变。
- 最终仍导出原有8帧，不修改Codex客户端或pet格式。

## 运动约束
- 上半身保持直立，头/卷轴不前倾，身体上下起伏不超过约1像素。
- 两腿错开半个周期，同一条腿始终保持前后遮挡身份。
- 支撑脚先落地、承重、向后推移；摆动脚沿低弧线回到前方。
- 脚底抬离地面的幅度约4–6像素，避免高抬腿、脚尖瞬移或双腿纠缠。
- 保留客户端120ms×7+220ms的帧时长；最后一帧靠近稳定落脚，消除悬空停顿。
- 从原始分层素材渲染每帧，避免重复缩放造成模糊。

## 验收
- 原尺寸连续序列及脚部放大对照。
- 记录每帧近/远脚的位置、支撑关系和首尾路径。
- 重点检查接缝、膝踝连接、脚底、躯干直立、手与卷轴接触。
- 用户指出的前倾、随机换腿和支撑跳变属于阻断问题，不作为轻微问题放过。
